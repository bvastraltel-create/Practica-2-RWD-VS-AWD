# Practica 2: RWD vs AWD

Este repositorio contiene la implementacion de un catalogo de hardware utilizando dos arquitecturas de interfaz:
1. **Responsive Web Design (RWD)** (`/responsive`): Un unico payload entregado al cliente con adaptacion visual mediante CSS Grid/Flexbox y `<picture>`.
2. **Adaptive Web Design (AWD)** (`/adaptive`): Deteccion de dispositivo mediante `User-Agent`.

## Requisitos Previos
* Node.js 24.0 o superior
* NPM v7.0 o superior

## Instalacion y Ejecucion Local
Si ya tiene instalado Node puede saltar al paso 3

1. Puedes descargar e instalar la versión recomendada (LTS) directamente desde el sitio web oficial: https://nodejs.org/. 

2. Una vez instalado, abre tu consola de terminal (CMD o PowerShell) y verifica que esté correctamente configurado ejecutando: node -v

3. Clonar el Repositorio e Instalar Dependencias: abre la terminal y navega hasta la carpeta del proyecto da clik en descarga e instala las dependencias necesarias: npm install

4. Inicia el servidor ejecutando: npm start

4. Acceso a las Rutas en el Navegador

5. Una vez iniciado el servidor en el puerto 3000, puedes acceder a las dos arquitecturas implementadas desde el navegador por el link correspondiente a cada verision:

Versión Responsive (RWD): http://localhost:3000/responsive

Versión Adaptativa (AWD): http://localhost:3000/adaptive
